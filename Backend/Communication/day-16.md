# Day 16: Structuring a Talk: Storytelling for Impact

**Week 3 · Public Speaking & Presentations**

## 🎯 Learning Objectives
- Structure a message using a clear narrative arc
- Use story to make abstract points concrete and memorable
- Identify the single core message of any talk before building the rest

## 📚 Topics
- The narrative arc: setup, conflict/tension, resolution
- The 'one big idea' principle
- Using specific, concrete stories instead of abstract claims
- Openings and closings that anchor the message

## 💡 Core Ideas
- Almost every memorable talk has exactly ONE core idea everything else supports — if you can't state your talk's single sentence takeaway, your audience won't be able to either.
- Facts tell, but stories sell: a specific, concrete story about one person or moment is dramatically more memorable and persuasive than the same point made abstractly with statistics alone.
- A narrative arc (setup → tension → resolution) works for a 2-minute update as much as a TED talk — tension is what earns attention; resolution is what earns the payoff.

## 🛠️ Practice Exercises
- [ ] Pick a topic you'll need to present soon (work update, personal story, pitch). Write its ONE-sentence core message before anything else.
- [ ] Find or write a specific, concrete story (a real moment, not a generalization) that illustrates that core message.
- [ ] Outline the talk using setup → tension → resolution, even if it's only 2 minutes long.

## 🪞 Reflection Prompts
Write these out, don't just think them:

- What's the one-sentence core message of a talk or pitch you'll need to give soon? Could you state it clearly right now, unprompted?
- What's a story (yours or someone else's) that illustrates a point you often make abstractly?
