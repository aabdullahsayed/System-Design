# Day 8: HTTP Fundamentals & REST Principles

**Week 2 · Web Fundamentals & REST APIs**

## 🎯 Learning Objectives
- Explain how HTTP requests/responses work
- Apply REST conventions correctly
- Design a clean resource-oriented API

## 📚 Topics
- HTTP methods, status codes, headers
- REST resource naming & idempotency
- Request/response body design
- API versioning basics

## 🟣 C# / .NET Focus
- Preview ASP.NET Core's request pipeline conceptually.
- Use a tool like `curl`/Postman/Bruno against a public API.

## 🟠 Java Focus
- Preview Spring Boot's `DispatcherServlet` conceptually.
- Use a tool like `curl`/Postman/Bruno against a public API.

## 🛠️ Hands-On Task
Without writing a server yet: design (on paper/markdown) the REST API for a 'Bookstore' — list resources, endpoints, HTTP methods, status codes, and example JSON payloads for a `Book` resource (CRUD + search). This design doc will drive Days 9–14.

## 🚀 Stretch Goal
Add pagination and filtering query-parameter design to your spec.
