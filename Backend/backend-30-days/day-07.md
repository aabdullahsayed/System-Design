# Day 7: Week 1 Capstone: CLI Task Manager

**Week 1 · Language & OOP Foundations**

## 🎯 Learning Objectives
- Combine OOP, collections, exceptions, and file I/O into one project
- Practice designing a small, cohesive application from scratch

## 📚 Topics
- Application design & separation of concerns
- Command parsing
- Persistence to a local JSON file
- Basic unit testing intro (preview of Week 4)

## 🟣 C# / .NET Focus
- Structure with a `Models`, `Services`, `Program.cs` layout.
- Persist tasks to `tasks.json` using `System.Text.Json`.

## 🟠 Java Focus
- Structure with `model`, `service`, `Main.java` packages.
- Persist tasks to `tasks.json` using Jackson.

## 🛠️ Hands-On Task
Build a CLI Task Manager (in both languages) supporting: add task, list tasks, mark complete, delete task, and persist to a JSON file between runs. Validate input and handle errors without crashing. Include a README with usage examples.

## 🚀 Stretch Goal
Add due dates and a command to list overdue tasks, sorted by urgency.
