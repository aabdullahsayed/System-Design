# Practice — Git & Collaboration

1. Create a new local git repo, make 3 commits with clear, descriptive messages, and review the history with `git log --oneline`.
2. Create a feature branch, make a change, and merge it back into `main` — then repeat using `rebase` instead of `merge`, and compare the resulting history.
3. Deliberately create a merge conflict (edit the same line on two branches), resolve it manually, and complete the merge.
4. Push a repo to GitHub/GitLab, open a Pull Request against a feature branch (even solo, against yourself), and write a proper PR description following `Code-Review.md`'s guidance.
5. Practice `git stash`: start editing a file, stash the change, switch branches, switch back, and pop the stash to resume.
6. Find an open-source project on GitHub with active PRs — read through 2-3 real code review comment threads to see these practices applied in a real team setting.
