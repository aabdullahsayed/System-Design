6. Identify (from any real codebase you have access to, or an open-source project on GitHub) one example each of: Singleton, Factory, and Decorator patterns in actual use.
7. Explain in your own words: why is an O(n²) nested-loop database query pattern (an "N+1 query" issue) a real, common production bug, and how would you rewrite it?
