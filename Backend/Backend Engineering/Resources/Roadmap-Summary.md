# Roadmap Summary — Full Path at a Glance

A one-page overview of the entire journey, useful for tracking progress or explaining your learning path to others.

## Beginner (Folders 01-04)
- **Programming Fundamentals**: data structures, algorithms, OOP, design patterns, clean code.
- **Git & Collaboration**: version control, branching strategies, code review practices.
- **Databases**: SQL fundamentals, relational design, normalization, indexing, transactions/ACID, NoSQL basics.
- **APIs & Web Fundamentals**: HTTP, REST API design, GraphQL, gRPC basics.

**Checkpoint**: you can build and ship a working REST API backed by a real database.

## Intermediate (Folders 05-09)
- **Authentication & Security**: authentication vs authorization, JWT, OAuth2, password security, HTTPS/TLS, common vulnerabilities (OWASP Top 10).
- **Caching**: caching strategies, Redis, CDNs, cache invalidation.
- **Message Queues & Async**: why async processing matters, message queues, pub/sub, background jobs, event-driven architecture.
- **System Design Basics**: scalability concepts, CAP theorem, load balancing, database scaling.
- **Testing**: unit testing, integration testing, TDD, mocking.

**Checkpoint**: you understand how real systems scale and can reason about trade-offs, not just write code.

## Advanced (Folders 10-14)
- **DevOps & Deployment**: Docker, CI/CD, Kubernetes basics, environment configuration.
- **Microservices**: monolith vs microservices, inter-service communication, API gateways, service discovery, the Saga pattern.
- **Scalability & Performance**: vertical vs horizontal scaling, database scaling, concurrency/parallelism, performance profiling.
- **Observability**: logging, metrics/monitoring, distributed tracing.
- **Advanced Topics**: CAP theorem deep dive, consensus algorithms (Raft/Paxos), idempotency, rate limiting.

**Checkpoint**: you can design and reason about production-grade, distributed backend systems.

## Interview Prep (Folder 15)
Common theory questions, full system design interview practice scenarios, and a compressed cheat sheet for final revision.

## Suggested pacing (a realistic guideline, not a rule)
- **Beginner section**: 4-8 weeks, if starting from limited prior programming experience.
- **Intermediate section**: 6-10 weeks, ideally while building a real project alongside the reading.
- **Advanced section**: 8-12+ weeks — this is genuinely senior-level material; expect to revisit these topics repeatedly as you gain real production experience, not master them in a single pass.

## The most important habit throughout
**Build something real at every stage.** Reading about caching or message queues without ever actually implementing one yourself builds recognition, not real understanding. Every folder's `Practice.md` exists specifically to force this; don't skip them.
