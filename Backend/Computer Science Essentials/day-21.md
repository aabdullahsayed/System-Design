# Day 21: Week 3 Capstone: Systems Concepts Review

**Week 3 · Advanced Algorithms & Systems**

## 🎯 Learning Objectives
- Tie DP, greedy, OS, and networking concepts together
- Practice explaining systems concepts clearly (a core engineering communication skill)

## 📚 Topics
- Cross-topic synthesis
- Explaining technical concepts simply (the 'explain to a smart 12-year-old' test)

## 💡 Core Ideas
- Being able to *explain* a concept simply is a stronger signal of understanding than being able to recite its definition — this capstone is about communication, not new material.

## 🛠️ Practice Exercises
- [ ] Write a one-page 'cheat sheet' summarizing DP, greedy, processes/threads, and networking — in your own words, no copy-pasted definitions.
- [ ] Solve one more DP problem and one more graph shortest-path problem, timed, to reinforce Week 3's algorithmic content.
- [ ] Explain (out loud, to yourself or someone else) 'what happens when you load a webpage' in under 3 minutes without notes.

## 🎤 Interview-Style Questions
Try answering these out loud, without notes, before checking any reference:

- Which Week 3 topic would you most want a follow-up deep dive on, and why?
