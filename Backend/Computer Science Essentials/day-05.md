# Day 5: Stacks & Queues

**Week 1 · Data Representation & Complexity**

## 🎯 Learning Objectives
- Use stacks and queues to solve ordering problems
- Implement both using arrays and linked lists
- Recognize LIFO vs FIFO problem shapes

## 📚 Topics
- Stack operations (push/pop/peek) and use cases
- Queue operations (enqueue/dequeue) and use cases
- Deque (double-ended queue)
- Implementing a queue using two stacks (and vice versa)

## 💡 Core Ideas
- Stacks model 'undo', nested structure matching (brackets, function calls), and DFS.
- Queues model 'process in arrival order' — BFS, task scheduling, buffering.
- The call stack in every running program is a literal stack — recursion depth is stack depth.

## 🛠️ Practice Exercises
- [ ] Implement a stack and a queue from scratch (array-backed and linked-list-backed).
- [ ] Implement: valid parentheses/brackets checker using a stack.
- [ ] Implement: a queue using two stacks.
- [ ] Implement: evaluate a postfix (RPN) expression using a stack.

## 🎤 Interview-Style Questions
Try answering these out loud, without notes, before checking any reference:

- How would you implement a 'min stack' that returns the minimum element in O(1)?
- Why is a queue the right structure for BFS but a stack the right one for DFS?
- What causes a 'stack overflow' and how does it relate to recursion depth?
